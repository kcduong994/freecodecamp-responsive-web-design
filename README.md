## Curriculum areas

- **HTML foundations:** elements, attributes, headings, links, lists, images, and page structure.
- **Semantic HTML, forms, and tables:** meaningful markup, labels, validation, tabular data, and content organization.
- **Accessibility:** alternative text, keyboard access, semantic controls, and readable document structure.
- **CSS foundations:** selectors, cascade, specificity, inheritance, box model, units, colors, and typography.
- **Layouts and responsive design:** Flexbox, Grid, positioning, media queries, and mobile-friendly layouts.
- **Advanced styling:** pseudo-classes/elements, CSS variables, transitions, transforms, and animation.
- **Portfolio and certification:** five required projects, review, and certification exam.

## How the learning archive works

1. Work through the official freeCodeCamp V9 challenge in its own editor.
2. Update only the files and requirements needed for the current lesson; do not pre-implement later lessons.
3. When a workshop, lab, or certification project is complete, save its **full working source** and relevant media assets.
4. Open the HTML file locally (or through VS Code Live Server if appropriate). Check page appearance, responsiveness, links, form semantics, and browser console. A local preview is not equivalent to freeCodeCamp's test result.
5. Add a project-specific README: objective, requirements, technologies, file structure, steps completed, tests, and lessons learned.
6. Update the root README with accurate counts, then commit/push on `main`.
7. After finishing the practical curriculum, consolidate theory in `RWD_REVIEW.md` and prepare for the official examination.
